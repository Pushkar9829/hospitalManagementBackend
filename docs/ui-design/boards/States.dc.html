Developer handoff

Screen states every page must handle

Use these patterns on every module screen. API error codes follow the API documentation in the specification PDF.

1 · Empty
No admissions todayAdmitted patients will appear here.
Say what will appear and offer the next action. Never show an empty table with only headers.
2 · Loading
Skeleton rows in the real layout, not a full-page spinner. Show after 300 ms. Buttons show a spinner and stay disabled while saving.
3 · Error (500 / network)
We could not load the bed board.
Check your connection and try again. If it keeps happening, share this code with support: c1b7e0a2
Always show the requestId from the API error. Unsaved form input is kept.
4 · No permission (403)
You don't have access to Payroll

Ask your Hospital Admin to add the permission payroll:run:read to your role.

Back to dashboard
Name the missing permission. Menu items without permission are hidden, so this appears only on direct links.
5 · Module not subscribed (402)
Radiology is not in your plan

Add it for ₹2,500 a month. Today's charge is ₹1,667 plus GST for the rest of this cycle.

Add module
Only Super Admins see the Add button. Others see "Ask your administrator".
6 · Subscription banners
Payment failed. Update your payment method within 7 days to avoid read-only mode. Fix now
Read-only mode. You can view and print. New bills, admissions and orders are paused. Patient charts stay available.
Banner sits above the page header on every screen.
7 · Confirm a risky action
Cancel bill OP/26-27/000155?

This sends a cancellation request to the Billing Manager. The bill stays valid until approved.

Name the object in the title. The destructive button states the action, never just "OK".
8 · Waiting for approval (202)
Sent for approval. The 15% discount is waiting for the Billing Manager. You'll be notified when it is decided.
Show where the request is waiting. The record shows a "Pending approval" badge until decided.
9 · Toasts and validation
Bill OP/26-27/000154 saved and printed.
Bed W2-204-B was just taken. Pick another bed.
Enter a 10-digit mobile number
Toasts last 5 s and never carry the only copy of an error. Field errors sit under the field.
10 · Session expired
You were signed out after 15 minutes idle

Sign in again to continue. Your unsaved note has been kept on this device.

Sign in again
11 · Offline or slow network
You're offline. Changes on this form are saved on this device and will be sent when you reconnect.
Phase 1 has no full offline mode. Forms keep input locally and retry; billing and dispensing wait for the network.
